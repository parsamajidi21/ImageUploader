Flash disk images to USB, without the bloat.

ImageUploader writes compressed disk images to USB drives and SD cards, and creates backups. It's small, has no dependencies, and runs on Linux, Windows and macOS.

Get ImageUploader View on GitHub

Free, no account, no telemetry, no ads.

Simple on purpose

Pick an image, pick a drive, press Write. Everything else is handled for you.

Reads compressed images on the fly

.gz, .bz2, .xz and .zst images, plus .zip (incl. ZIP64), .zzz, .tar, .cpio and .pax archives. No need to extract first.

Hard to make a mistake

It tries to be bullet-proof: your system disk is kept out of the target list, so you won't overwrite your OS by accident.

Verified, synchronized writes

Compares the disk to the image as it writes. All data is physically on the drive when the progress bar hits 100%.

Backups too

Read a drive back to a raw image or a ZStandard-compressed one with a single click.

Serial line to microcontrollers

Send images straight to embedded boards over a serial port, with a configurable baud rate.

18 languages, native everywhere

GDI on Windows, Cocoa on macOS, GTK or X11 on Linux. It picks up your system language on its own.

Small and self-contained

No runtime to install and no extra libraries: every parser and decompressor is built in.

Private by design

No telemetry, no tracking, no ads, no accounts. Fully GDPR compatible.

A clean, modern interface

Everything on one screen: the image, the drive, and a Write button that looks as serious as what it does. It follows your system theme, dark mode included.

  • Drag and drop an image file anywhere on the window
  • Refresh button to pick up a drive you just plugged in
  • Write is clearly marked as the action that erases the drive
  • Smart file filter for every supported image and archive format
  • Live progress with an estimate of the time left
  • Speaks your language: 18 translations, detected automatically

Get ImageUploader

Download version 1.0.0 for Linux (x86_64, Ubuntu 22.04 / Debian 12 or newer), or build it from source. All files and checksums are on the Releases page.

Ubuntu / DebianGTK · .deb · recommended Linux GTKportable .zip · needs udisks2 Linux X11portable .zip · minimal Linux X11 + fontfor systems without Unicode fonts

Install the .deb with sudo apt install ./imageuploader_1.0.0-amd64.deb. Windows and macOS: build from source for now.

Linux (GTK, recommended)

# Debian / Ubuntu dependencies
sudo apt install build-essential libgtk-3-dev
# optional, lets non-root users write via udisks2
sudo apt install libudisks2-dev

git clone https://github.com/parsamajidi21/ImageUploader.git
cd ImageUploader/src
USE_GTK=1 make
./imageuploader

Other interfaces and packages

# default: X11 on Linux, GDI on Windows, Cocoa on macOS
make

USE_TUI=1 make      # text interface
USE_WRONLY=1 make   # write-only

make install        # install under /usr
make deb            # build a .deb package
make help           # list every option

Three steps

That's the whole manual.

Choose an image

Click the folder button or drag an .iso, .img, .xz, .zip… file onto the window.

Choose a drive

Plug in your USB stick or SD card and select it from the list. Hit refresh if it isn't there yet.

Write

Press Write. When the progress bar reaches 100%, the data is on the drive and verified.

Why not just use dd?

If you're comfortable with the command line, dd works. For everyone else:

  • It's for people who'd rather not touch a terminal
  • dd isn't cross-platform; Windows needs an app anyway
  • Compressed images are read directly, no pipes needed
  • Writes are verified against the image
  • Data is guaranteed to be on the device when it says done
  • It keeps you away from your system disk
  • It's a native application on every platform, not a dd wrapper
  • No extra DLLs: all parsers and decompressors are built in
